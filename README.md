# 💳 RecoverAI – AI Revenue Recovery Platform

> **RecoverAI** is an AI-powered revenue recovery platform built for **Razorpay Buildathon 2026 – Track 03: AI Revenue Recovery**. It detects at-risk payments, recommends intelligent recovery actions using Google Gemini AI, provides explainable AI decisions, and maintains a complete audit trail for enterprise-grade transparency.

---

## 🚀 Overview

Revenue loss can occur due to failed payments, transaction errors, or delayed recovery actions. RecoverAI helps businesses identify these issues early and supports faster, more informed recovery decisions.

The platform combines AI-powered recommendations, analytics, and audit logging into a single dashboard to improve operational efficiency and reduce revenue leakage.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/RecoverAI.git
```

Go to the project folder

```bash
cd RecoverAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.streamlit/secrets.toml` file

```toml
GEMINI_API_KEY="YOUR_API_KEY"
```

Run the application

```bash
streamlit run login.py
```
